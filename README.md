# 炸金花多人对战

## 本地运行
1. 安装 Node.js 18 或更高版本。
2. 在项目根目录执行 `npm install`。
3. 执行 `npm test` 运行规则测试。
4. 执行 `npm start` 启动服务器。
5. 浏览器打开 `http://localhost:8080`。

## 部署
项目使用 WebSocket，部署平台必须支持长连接，并设置启动命令 `npm start`。更新线上仓库前请先备份。

## 看牌与闷牌比牌
- 发牌后底牌默认隐藏，玩家点击“看自己的牌”后，才会在自己的界面显示；看牌不消耗行动，也不会把底牌发送给其他玩家。
- 仅剩两名未弃牌玩家时，未看牌的玩家可以使用“闷牌比牌”挑战已下注的最后一名对手；挑战费用为当前有效闷注额，输家淘汰。
- 普通比牌仍要求发起者已看牌，并遵守第一位看牌玩家不能发起普通比牌等限制。

## 断线规则
- 玩家断线后立即退出房间，当前牌局中视为弃牌。
- 已投入奖池的底注、下注和比牌费不退还；断线事件本身不改变其他玩家积分。
- 不提供断线重连、恢复资格、重连 Token 或 120 秒保留机制。
- 同一房间会记录断线玩家昵称，拒绝该昵称再次加入。由于本项目没有账号系统，这属于昵称级限制，不等同于跨设备的真实身份验证。

## 测试状态
运行 `npm test` 可执行规则测试；`node --check server.js` 检查服务端语法。自动化测试通过不代表已完成 Render 线上部署或真实多设备端到端测试。
